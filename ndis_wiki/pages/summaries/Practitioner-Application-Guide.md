# Summary: Quick Reference Guide - NDIS Behaviour Support Practitioner Application

## Overview
A technical guide for individuals applying to be considered suitable as an NDIS [[Behaviour-Support-Practitioner]].

## Application Process
- Requires a **PRODA** account for access to the Applications Portal.
- Applicants must provide personal details, employment history, and qualifications.
- **Self-Assessment:** Applicants must complete a self-assessment against the **Positive Behaviour Support Capability Framework**.
- **Levels:** Capability is assessed at Core, Proficient, Advanced, and Specialist levels.
- **Evidence:** Requires a resume, certified qualifications, and a supervisor's endorsement.
